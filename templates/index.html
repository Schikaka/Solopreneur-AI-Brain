Privacy & Security

NarrativeAI uses a zero-retention upload flow for client CSVs.

  • Uploaded CSVs are read from the request stream into RAM and are never written to an uploads folder.
  • The server returns the generated report, then drops the in-memory CSV bytes after the request finishes.
  • The Local History Vault uses IndexedDB, so saved reports remain on this browser and machine.
  • Only derived report stats and narrative output are saved locally; raw CSV files are not saved.
